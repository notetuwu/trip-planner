    Trip chat

    API keys

    Optional: with a key you can plan with cloud models that search the web themselves. You pay the provider per use (a long trip with research on a top model can cost a dollar or two; smaller models much less; the cost is shown after each plan where known). Keys are kept in keys.json in the planner folder, only sent to that provider, and never included in saves or exports.

    Plan a route

    Describe the trip; your selected model suggests where to stay, and every leg is checked against the real roads. You can change the stays afterwards, then generate the itinerary as usual.

    Import a place list

    Mark everything that looks interesting in Google Maps, save it to a list, and bring it in here. The places show on the map and under Places, ready to star.

    From Google Maps

    1. In Google Maps, open Saved and the list.
    2. Tap Share and turn on Anyone with the link.
    3. Copy the link and paste it here.
    It re-syncs by itself when it's more than an hour old.

    From a CSV file

    For example from Google Takeout → Saved, which has one file per list.
